Place the exported Blender scene here as thailand.glb.

The .blend file is not automatically converted by GitHub Pages. Export glTF 2.0 (.glb) from Blender, include materials and vertex colors. Blender shader graphs that multiply texture with color attributes may require baking or Godot material reconstruction. Keep an original backup.

This starter currently has a temporary ground and placeholder character; collision for imported scenery must be configured separately before production use.
