# NexTgenLeo — initial game design notes

This is a **planning reference**, not implemented gameplay.

- Class 0–10, level 1–100 within each class; class advancement resets level to 1.
- Six planned elements: Earth, Water, Wind, Fire, Lightning, Wood.
- Class 3: progression path; Class 5: profession; Class 7: faction; Class 10: final tier.
- Planned 12 professions, guild/element/faction wars.
- Equipment rarity Common through Legendary and equipment evolution from +0.
- Pets level 1–100 with five evolution phases and auto-loot.
- Male/Female modular characters, separate wearable parts.
- MMORPG requires authoritative server design; browser prototype is offline for now.

**Important:** exact choice-by-choice specification from the earlier design session must be checked before implementing progression, balance, or class trees.
