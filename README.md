# NexTgenLeo — Clean Godot 4 Project

This repository was intentionally reset on 2026-10-24 at the owner's request. All previous game files were removed from the current main branch snapshot. Earlier Git commits may still contain historical files.

## Start
1. Open this repository in Godot 4.4+ using `project.godot`.
2. Press F5 to launch the clean 3D scene.
3. The project is intentionally empty except for a camera, lighting and a simple ground plane.

No older characters, UI, gameplay, map assets, or web exports have been imported. Add the real Thailand map and character assets only when ready.

GitHub Pages browser deployment is not yet configured. A Godot Web export must be built before the game can run in Chrome.
