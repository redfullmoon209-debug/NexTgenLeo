# NexTgenLeo Thailand - Godot 4 starter

Open the `godot` folder with Godot 4.4+ and press F5.

## Playable prototype and class progression

- Third-person 3D movement, follow camera, touch move/look and keyboard controls.
- Ten temporary monsters, target selection, basic attacks, EXP, levels, Gold and local save.
- New characters start as Novice with three starter skills.
- At Lv.10 choose one of six elements; at Lv.15 choose one of six paths; at Lv.30 choose one of two specializations in that path.
- Each final specialization has its own 14-skill deck. Three skills are equipped at a time; further skills unlock as the character levels.
- Every character level grants one Skill Point. Upgrade an unlocked skill with one Skill Point plus Gold; skill rank is capped by character level and damage scales with level and skill rank.
- Skill range, damage, cooldown and area attacks follow the class weapon. Temporary procedural armor and weapon meshes are generated by Godot, with +0 to +10 equipment upgrades and a 35% Ore drop chance.
- Hunt quest, healing potion, mobile action buttons and optional Thailand GLB map. The green prototype field remains until `godot/assets/maps/thailand.glb` is supplied.

Models use basic Godot meshes as replaceable placeholders. This is a local single-player prototype: there is no server-authoritative multiplayer, account system, shared economy or live 20-player tournament yet. Monsters follow the player but do not deal damage. The workflow builds an HTML5 export and stores it as a GitHub Actions artifact; it does not publish a public Pages site.

## Run and export

Import `godot/project.godot` in Godot 4.4+, wait for import, then press F5. The repository workflow exports a web build from branch `godot-thailand-3d`.

## Safety

This prototype is on branch `godot-thailand-3d`; the main branch remains unchanged. It is not a finished MMO.
