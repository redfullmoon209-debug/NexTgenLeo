# NexTgenLeo implementation status

## Available now
- Godot 4.4.1 GL Compatibility 3D browser prototype
- Procedural placeholder forest, capsule player, follow camera
- PC WASD/Shift/Space, mobile virtual joystick, run/jump
- Mouse camera orbit and wheel zoom
- GitHub Actions web export and Pages deployment
- Autoload gameplay state: Class 0–10, level 1–100, EXP, stat recalculation, gates for element/job/faction, inventory stacks (200 slots), currency placeholders

## Not implemented yet
- Actual Male/Female modular character assets, rigs, animations, equipment meshes
- Twelve job definitions, combat and skills, mobs, quests, NPCs, zones
- Full bag/shop screens, pet models, auto-loot, evolution, equipment enhancement
- Network server, accounts, persistence, security, guilds, PvP, faction wars
- Mobile device and browser acceptance tests

## Important
Current progression/inventory is local in-memory prototype logic. Do not use it as authoritative server state. Balancing and exact earlier game-design choices still need validation.
